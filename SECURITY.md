# Segurança

O Rotaz guarda chaves de API de provedores. Se você encontrar uma falha de segurança, **não abra uma issue pública**.

Use o relatório privado de vulnerabilidades do GitHub: aba **Security → Report a vulnerability** deste repositório. Descreva o problema, como reproduzir e a versão afetada. A correção sai numa nova versão.

Como o Rotaz protege chaves, painel e gateway está descrito no README, na seção "Segurança", e em https://rotaz.dev/docs-seguranca.html.
